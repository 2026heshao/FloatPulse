# FloatPulse v4.7.0 插件包清单

插件**不随主程序打包**，按需下载。下载后把 `.fpplug` 放进程序目录的 `plugin_store\` 文件夹，再到「插件中心 → 🏪 插件商店」点安装。

| 插件包 | 名称 | 版本 | 体积 | 页面 / 热键 | 能力 | 说明 |
|---|---|---|---|---|---|---|
| `ai-assistant.fpplug` | AI 助手 | 1.8.0 | 25.9 KB | 🤖 AI 助手 / `Ctrl+Alt+I` | 🌐 网络 ✍ 写入 🛠 改删 🧠 AI 总配置 | 本地 / 云端双后端的对话助手：读应用内任务、碎片、笔记做总结、分类与问答，规则库自定义 AI 行为 |
| `ai-text-workshop.fpplug` | AI 文本工坊 | 1.4.0 | 11.7 KB | ✂ 文本工坊 / `Ctrl+Alt+T` | 🌐 网络 ✍ 写入 🧠 AI 总配置 | 剪贴板一键 AI 加工：主窗口侧栏「✂ 文本工坊」页（或热键 `Ctrl+Alt+T`），原文自动带入剪贴板内容，一键润色成邮件、翻译、总结要点、改写正式、提取待办并转任务。 |
| `kb-search.fpplug` | 站内搜索 | 1.0.0 | 21.6 KB | 🔍 站内搜索 / `Ctrl+Alt+F` | 只读 | 在知识库 / 笔记 / 碎片 / 任务 / 素材里做全文检索：自研中文分词 + 倒排索引 + BM25 排序，命中片段带高亮，点结果标题跳转到对应面板。纯站内检索，不碰文件系统 |
| `recurring-tasks.fpplug` | 周期任务 | 1.0.0 | 18.1 KB | 🔁 周期任务 / `Ctrl+Alt+R` | ✍ 写入 | 只给规则（每天 / 每周几 / 每月几号 / 每 N 天），到点自动生成任务；错过的补一次、同一天不重复生成 |
| `weekly-report.fpplug` | 日报 / 周报草稿 | 1.0.0 | 10.7 KB | — / `Ctrl+Alt+W` | 只读 | 日报 / 周报草稿（weekly-report） |

> 程序本体不含插件；核心功能（悬浮球 / 碎片 / 任务 / 笔记 / 知识库 / 素材 / 截图钉屏 / 软件网址导航）不受插件安装与否影响。
