UNDER THE HOOD

好看的皮囊，靠谱的里子

UI / 业务 / 数据三层解耦，每一处异常都有兜底——工具软件，稳定是第一颜值。

atomic_write所有数据先写临时文件再 os.replace，写一半断电也不会损坏。
single_instanceWindows 互斥量防重复启动，双击多少次都只有一个实例。
docx_syncmtime + sha1 双指纹检测外部修改，段落级 hash 比对内容变更，改完弹窗询问重载。
exception_hook全局异常钩子：出错弹窗告诉你原因，绝不静默崩溃。
data_isolation六类数据各自独立成文件，id 自增不复用，删除严格按 id 过滤。
edge_fallback分辨率变化、多屏漂移后窗口位置自动兜底，永远找得到。
clipboard_lru剪贴板历史上限可配置（默认 200 条），LRU 自动淘汰，内存占用有上界。
theme_engineQSS 模板 + 颜色字典统一管理浅深双主题，改一处常量即换全局配色。

怎么安装？三步就能跑起来吗？

比三步还少：下载压缩包 → 解压到任意文件夹（建议别放 C 盘 Program Files，放桌面或 D 盘都行）→ 双击启动程序。悬浮球会常驻桌面角落，主窗口从球上右键唤起。不写注册表、不需要管理员权限。

需要先安装 Python 或其他运行环境吗？

不需要。所有依赖（含 PyQt6 界面框架）都打包在程序文件夹里，开箱即用；这也是为什么整个文件夹会比较大——它把运行环境整个背在身上，换给你省去配环境的麻烦。

我的数据存在哪里？

就在程序文件夹的 data/ 目录里——JSON 明文存储 + 知识库.docx，随时可以自己备份、自己看。没有数据库、没有加密黑盒，你的数据始终是你的。

会偷偷联网吗？

不会。FloatPulse 没有任何云端依赖，断网状态下所有功能照常可用。不收集数据、不上传文件、没有账号体系。

卸载麻烦吗？会不会留残留？

把程序文件夹删掉就完成了——数据也在里面，删前记得先备份 data/ 目录。没有注册表项、没有开机自启、没有后台进程残留。

换电脑怎么办？

整个文件夹拷走即用，数据跟着走——碎片、笔记、任务、知识库一起搬家，不断档。

和我已经在用的剪贴板 / 截图工具有什么区别？

剪贴板工具只管"收"，FloatPulse 把收、存、翻出来再用做成了闭环：碎片能合并成笔记，段落能存进知识库做成轮播卡，任务能直接在球上记——不替代谁，而是把散落的动作接成一条线。

常驻后台会不会拖慢电脑？

它只监听剪贴板这一个系统事件，不带任何联网服务和后台扫描；剪贴板历史有上限（默认 200 条，LRU 自动淘汰），内存占用有上界，普通办公本长期挂机无压力。
