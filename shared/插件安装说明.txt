FloatPulse 插件安装说明
======================================================================

主程序包里【不含任何插件】——插件按需下载，只装你要用的那几个。
不装插件不影响任何核心功能：悬浮球、碎片、任务、笔记、知识库、素材、
截图钉屏、软件/网址导航全部照常可用。

----------------------------------------------------------------------
一、去哪下载插件
----------------------------------------------------------------------
在 GitHub 的 Release 页面，展开「Assets」区，里面有若干 .fpplug 文件，
每个是一份独立插件，单独下载即可（每个只有 10~40 KB）：

  ai-assistant.fpplug       AI 助手：完整聊天页，本地/云端双后端
  ai-text-workshop.fpplug   AI 文本工坊：复制一段话 → 加工 → 落回碎片/笔记/任务
  kb-search.fpplug          站内搜索：中文全文检索（碎片/笔记/任务/知识库/素材）
  recurring-tasks.fpplug    周期任务：只给规则，到点自动生成任务
  weekly-report.fpplug      周报草稿：汇总区间内已完成任务、碎片与番茄次数

----------------------------------------------------------------------
二、放到哪里
----------------------------------------------------------------------
把下载到的 .fpplug 文件放进本目录下的 plugin_store\ 文件夹。
不需要解压，不需要改名。

  FloatPulse\                        ← 解压后的程序目录
  ├── FloatPulse.exe                 ← 双击运行
  ├── plugin_store\                  ← 【插件包放这里】商店目录
  ├── plugins\                       ← 程序安装插件的位置，留空即可
  ├── float_data\                    ← 你的数据（碎片/笔记/任务/知识库.docx）
  └── 插件安装说明.txt               ← 本文件

两个目录的区别：plugin_store\ 是你放"安装包"的地方，程序永不自动解压它；
plugins\ 是程序"装好之后"的位置。卸载插件只清掉 plugins\ 里的副本，
plugin_store\ 里的包会留着，随时能再装。

----------------------------------------------------------------------
三、怎么安装
----------------------------------------------------------------------
  1. 启动 FloatPulse（双击 FloatPulse.exe）
  2. 点悬浮球打开主窗口
  3. 左侧栏「系统」组 → 「🔌 插件中心」
  4. 点右上角「🏪 插件商店」，列表里会出现你刚放进去的插件包
  5. 点该包的「安装」，装完立刻生效，不需要重启

插件中心页面上也直接写着这两个目录的完整路径，放错地方时照抄即可。

----------------------------------------------------------------------
四、卸载与重装
----------------------------------------------------------------------
插件卡片上的「🗑 卸载」会二次确认，并列出将被删除的完整路径。
卸载只删 plugins\<插件id>\ 这一份副本，源包与插件的私有数据
（float_data\plugins\<插件id>\）都会保留 —— 想再装回来，
回「🏪 插件商店」点一次「安装」就行。

----------------------------------------------------------------------
五、联网与权限
----------------------------------------------------------------------
插件本身拿不到任何网络库，只能在 manifest 里声明能力、经宿主代理联网。
插件中心每张卡片会显示该插件声明了什么：

  🌐 网络访问   会经宿主发起 https 请求（只记 URL 与耗时进 float_data\app.log）
  ✍ 写入数据    能新增碎片/任务/笔记
  🛠 改删数据    能修改与删除已有数据（删除均带撤销令牌）
  🧠 AI 总配置  可接入设置页的「AI 总配置」，共用一套后端地址与 Key

不声明就没有对应能力，未声明的调用会被直接拒绝并记日志。
AI 相关插件可以用本机 llama-server 跑，全程不联网。

----------------------------------------------------------------------
六、自己做插件
----------------------------------------------------------------------
插件依赖只允许 PyQt6 + Python 标准库。开发说明见仓库：
docs/插件开发说明-2026-09-26.md
打包成 .fpplug 用仓库里的：python tools/pack_plugin.py plugins/<插件目录>
