## 目标

把设置页从「单页长滚动」重构为「左侧分类导航 + 右侧分类内容」的切换式布局（Windows 11 / macOS 系统设置范式）；「↺ 恢复默认设置」放底部常驻栏。纯布局重构，所有设置项的持久化、信号广播行为零变化。

## 改动

### 1. `v4/src/settings_panel.py`（主体）

- 新增模块级常量 `SETTINGS_CATEGORIES`：9 个 `(key, 图标, 名称)`——appearance 🎨 外观 / ball 🔵 悬浮球 / clipboard 📋 剪贴板与碎片 / assets 🖼 临时素材 / tools ⚡ 全局工具 / system 🚀 启动与系统 / export 📤 导出 / ai 🧠 AI 配置 / about ℹ️ 关于（不合并、不改名，尊重各组"同类项相邻"的既有注释语义）。
- `_build_ui` 重构为三段：
  - 顶部：pageTitle「⚙️ 设置」（保留）；
  - 中部 QHBoxLayout：左侧导航栏（宽约 140，9 个 `QPushButton#settingsNavBtn`，checkable + `QButtonGroup` 互斥）+ 1px 竖分隔线 + 右侧 `QStackedWidget`；每个分类页 = 独立 QScrollArea（沿用现 `settingsScroll` 配置）内含该分类的分组卡片；
  - 底部常驻栏：stretch + 「↺ 恢复默认设置」，移出滚动内容。
- 现有 8 组 + 关于的行构建代码**原样搬运**：共享的 `v` 换成各分类页自己的 vbox，`_group_card`/`_add_row`/`_toggle` 等辅助与全部 `_on_*` 处理器不动；AI 区的模式行显隐（`_ai_apply_mode_ui`）、AI_SERVER 监听注册、每页末尾 `addStretch()` 顶对齐，全部随分类迁移。
- 新增公开方法 `show_category(key)`：切到指定分类、未知 key 静默忽略——供导航点击与未来深链复用；默认落在「外观」分类，不做跨会话记忆。
- `refresh()` / `apply_theme()` 零改动（主窗口 `main_window.py:2452` 的联动不受影响）。

### 2. `v4/src/main_window.py`（小改）

- `show_settings_page()`（2408 行）加可选参数 `category=None`：切到设置页后调用 `_page_settings.show_category(category)`，默认行为不变。

### 3. `v4/src/theme.py`（QSS 追加）

在 `#settingsGroup` 段（约 493 行）旁追加 `QPushButton#settingsNavBtn` 三态样式（默认 / hover `$primary_a08` / checked `$primary_a18` + primary 文字 + `$primary_a30` 边框，照抄 240-267 行 `navBtn` 范式、去掉拖拽态）与 `QFrame#settingsNavDivider`（`$hair` 竖线）。checked 加粗在此无侧栏拖拽那种 sizeHint 重排风险（静态 VBox）。

### 4. 测试与收尾

- 新增 `v4/tests/test_settings_nav.py`：沿用 `test_plugins_panel.py` 的离屏 QApplication + SimpleNamespace 假 host 模式——分类常量完整性、构建后 stack 9 页 / 按钮 9 个、点击切换 + 互斥、`show_category` 生效与非法 key 容错、关键控件属性仍在（防搬运漏项）、底部重置按钮存在。
