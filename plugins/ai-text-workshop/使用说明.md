# AI 文本工坊

剪贴板一键 AI 加工：主窗口侧栏「文本工坊」页（或热键 `Ctrl+Alt+T`），原文自动带入剪贴板内容，一键润色成邮件、翻译、总结要点、改写正式、提取待办并转任务。

## 快速开始

1. 首次进入页面会自动展开「后端」设置卡：选预设（DeepSeek / 硅基流动 / 本地服务 / Ollama），填 API key（本地服务免 key），点「保存后端」。
2. 日常使用：复制任意文本 → 按 `Ctrl+Alt+T`（工坊页自动带入剪贴板）→ 点动作按钮 → 结果几秒出现。
   - 原文**超过 8000 字会自动截断发送**（防 token 爆炸），「处理中…」状态行会明确提示已截断，不会悄悄砍你的内容。
3. 结果可编辑，然后「复制结果」带去别处，或直接落进应用：
   - **存为碎片**：结果进碎片池，来源标记「插件:ai-text-workshop」；
   - **存为笔记**：标题自动取结果首行；
   - **转任务**：执行「提取待办」后可用，把识别到的行动项逐条写入任务列表。

## 历史与收藏（v1.5.0）

- **历史**：每个成功动作自动记录（最近 20 条，存插件私有目录），关页/重启都不丢。点「历史」展开卡片，**点条目即填回结果区**（可编辑、复制、再落库；「提取待办」的历史填回后「转任务」照样可用）；右键条目删除该条，「清空历史」一键清空
- **收藏指令**：把常用的自定义指令存成按钮（10 条上限）。写好指令 → 点「收藏指令」→ 输入框下方出现「按钮」，点击填入（不自动执行，可改完再跑）；右键按钮删除该收藏
- 历史只留**结果全文 + 源文前 120 字摘要**做辨识，不做全文存档；存档文件写坏时按空档启动、原文件保留

## 动作一览

| 动作 | 用途 |
|---|---|
| 润色成邮件 | 把随手写的内容变成得体的工作邮件（含主题行） |
| 翻成中文 / 英文 | 保留分段的整段翻译 |
| 总结要点 | 长文变要点列表（≤8 条） |
| 改写正式 | 口语化表达改成书面语 |
| 提取待办 | 从会议记录 / 聊天记录里挖出行动项，一键转任务 |
| 自定义指令 | 输入框写什么就执行什么，覆盖长尾需求 |

## 后端说明

三种后端来源，按优先级：

1. **接入 AI 总配置（推荐）**：在 设置 → AI 总配置 配好云端 / 本地（只配一次），在「接入插件」下拉框勾选本插件——之后本页后端设置停用，改动总配置即刻生效；
2. **本页私有配置**：未接入时用「后端」卡（云端 / 本地双模式，配置存插件私有目录）；
3. **本地推理**：本页「本地」浏览选择 llama.cpp 的 `llama-server.exe` 与 `.gguf`，点「启动」由插件拉起服务（默认端口 **8094**，退出 FloatPulse 自动结束、不占显存）；本地未就绪时执行动作会明确引导，不会发出注定失败的请求。

**省显存的共用玩法**：在「AI 助手」页启动本地推理后，本页云端区地址填 `http://127.0.0.1:8093/v1`、模型填 `local`；或直接接入 AI 总配置（宿主服务端口 8095）——两个插件并发使用同一个服务，不必各拉各的。

## 安全约定

- 只在点动作按钮 / 执行指令时才发请求，绝不后台静默上传；
- 发给模型的只有原文框里的文本，不附带应用内任务 / 碎片 / 笔记数据；
- 日志只记动作名与结果长度，不记内容；网络审计行（URL + 耗时）见 `app.log` 的 `[插件网络]`。

## 排障

| 现象 | 处理 |
|---|---|
| 401 / 403 | API key 缺失或无效，到「后端」检查 |
| 404 | 地址或模型名不对，地址应以 `/v1` 结尾 |
| 连接拒绝 | 本地服务没启动（去 AI 助手页启动），或端口不对 |
| 超时 | 模型响应慢，重试一次 |
