# 周期任务（recurring-tasks）

只给规则，到点自动把任务生成出来。适合「每周五写周报」「每月 1 号归档上月资料」「每 14 天复盘」这类**不需要你记日期、但必须按时出现**的事。

与宿主的「任务到期提醒」不重复：那个是「已经存在的任务快到期了，提醒你」；本插件是「你还没建这条任务，到点替你建」。

## 怎么用

1. 打开页面：主窗口左栏「周期任务」，或按 **Ctrl+Alt+R** / 悬浮球右键「周期任务」
2. 点「新建规则」，填三件事：**干什么**（任务标题 + 可选备注）、**什么时候**、**生成的截止日要不要有**
3. 保存即可。到点后任务会自动出现在「日程任务」页，和手动建的任务完全一样（照样享受到期提醒）

### 五种规则

| 类型 | 说明 |
| --- | --- |
| 每天 | 每天 HH:MM 生成一条 |
| 每周 | 可多选星期几（如周一、周三），到点各生成一条 |
| 每月 | 可多选号数（如 1、15、31）；**号数超过当月天数时自动顺延到月末**——所以「31 号」在 2 月不会消失，而是落在 2 月最后一天 |
| 每 N 天 | 从规则创建那天起算，每 N 天一条（N 取 1–365） |
| 每 N 周 | 可多选星期几，从**创建那周**起每 N 周一轮（N 取 1–52）——「每 2 周 周一」= 隔周一生成一条；周期锚点固定为创建那周的周一，编辑规则不会让周期漂移 |

### 生成任务的截止日

只影响生成出来的任务，不影响触发时刻：不设截止日 / 当天 / 次日 / 3 天后 / 7 天后。

### 周末顺延（可选）

新建 / 编辑规则时勾选「**周末触发日顺延到下周一**」：落在周六 / 日的触发日改到下一个周一的同一时刻生成，休息日不被任务打扰。多条周末日顺延到同一个周一也**只会生成一条**任务（自动合并）。不勾选的规则（包括升级前建的所有老规则）行为完全不变。

### 导出 / 导入与生成记录

- **导出规则**：全部规则存成 JSON 文件（备份 / 换机）；**导入规则**：从 JSON 并入，逐条校验，**重复的规则自动跳过**（以你现有的为准，不会被覆盖），坏数据计数提示
- 规则卡片上会显示**上次生成的任务标题与时刻**（取生成那一刻的规则标题，之后改标题也不会混淆历史）

## 三条需要知道的行为

- **程序没运行时不会自动生成**。页面上的「下次触发」是**推算值**——它只告诉你「如果程序开着，会在那时生成」。
- **错过的那一次，下次启动会补上，而且只补最近一次**。关了三天不会冒出三条任务，只补最近到点的那一次。
- **同一天不会重复生成**。重复启动程序、一天内多次检查、「立即检查」按几次，都只会产生一条。
- **新建的规则不会为「创建之前」的日子补生成任务**。规则从你保存它的那一刻起算：上午 10 点新建一条「每天 08:00」，今天不会补一条昨天的任务，第一次生成在明天 08:00；而 08:00 新建「每天 09:00」，今天 09:00 就照常触发。

## 数据与权限

- 规则存在插件私有目录：`float_data/plugins/recurring-tasks/rules.json`（可直接编辑，但请保持 JSON 合法）
- 规则文件写坏或读不出来时**只降级不删档**：程序按「还没有规则」启动，原文件保留供你手工抢救，日志里会写明原因
- 本插件只声明「写入数据」权限，且**只会新增任务**——不改、不删你已经有的任何数据。停用/卸载插件也不会删掉已生成的任务（它们已经是普通任务了）
- 想临时停用：主窗口左栏「插件中心」→ 本插件卡片上点「停用」。停用只会**停止生成**，不删除任何规则与任务；重新启用后照常按规则继续（期间错过的仍只补最近一次）

## 常见问题

- **「立即检查」点了提示没事发生？** 说明今天该生成的都已经生成过了（或规则已停用 / 还没到点 / 是今天刚建的且今天的触发时刻早于创建时刻）——这是正常的幂等行为，不是故障。
- **改了规则时间，今天会按新时间再生成一条吗？** 不会。同一天只生成一次。若今天还没生成过（例如原本设 23:00、今天还没到点，你改成 08:00 而现在已过 8 点），保存后下一次轮询（≤60 秒）或点「立即检查」就会按新时间生成今天这一次。
- **想让某条规则暂停一段时间？** 用卡片上的「停用」，别删规则——删掉会丢 `last_fired` 记录，重新建则等同于新建（水位重置），今天可能立刻触发一次。反过来，**停用再启用**是安全的：`last_fired` 保留，不会重复生成。
