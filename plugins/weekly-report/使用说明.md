# 日报 / 周报草稿（weekly-report）

一键把「这段时间干了什么」先替你写一遍：选定时间范围，自动汇总**已完成任务 + 本周期碎片（按类别分组）+ 番茄专注计数**，生成可编辑的 Markdown 草稿。

## 怎么用

1. 触发：悬浮球右键菜单「📝 生成日报 / 周报草稿」，或全局热键 **Ctrl+Alt+W**
2. 选时间范围：今天 / 本周 / 近 7 天 / 自定义起止日期
3. 预览窗口随即打开，草稿**随范围实时刷新**——切换范围或改起止日期，
   下方 Markdown 全文立即重算，不需要再点「生成」；正文可直接编辑
4. 导出三选一：复制到剪贴板 / 另存为 .md 文件 / 写入 Obsidian vault（需在设置页配置 vault 路径）

## 数据来源（只读，不改动你的数据）

| 内容    | 来源                                         |
| ----- | ------------------------------------------ |
| 已完成任务 | 按完成时间归入所选周期                                |
| 碎片    | 按内容类别分组展示                                  |
| 番茄计数  | 任务的累计 focus_sessions（按任务统计，非时间区间，报告内会如实标注） |

## 注意

- 草稿只是初稿，语气和取舍请自己把关后再交
- 「写入 Obsidian」需要先在设置页配置 vault 路径，否则该按钮不可用
- 插件只读宿主数据，不会修改/删除任务、碎片、笔记
- 想临时停用：主窗口左栏「🔌 插件中心」→ 本插件卡片上点「⏸ 停用」
  （停用后不挂右键菜单、不绑热键，随时可「▶ 启用」恢复）
