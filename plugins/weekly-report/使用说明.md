# 日报 / 周报草稿（weekly-report）

一键把「这段时间干了什么」先替你写一遍：选定时间范围，自动汇总**已完成任务 + 本周期碎片（按类别分组）+ 番茄专注计数**，生成可编辑的 Markdown 草稿；接好 AI 总配置后还能**一键润色成正式周报**。

## 怎么用

1. 触发：悬浮球右键菜单「生成日报 / 周报草稿」，或全局热键 **Ctrl+Alt+W**
2. 选时间范围：今天 / 本周 / 近 7 天 / 自定义起止日期
3. 预览窗口随即打开，草稿**随范围实时刷新**——切换范围或改起止日期，
   下方 Markdown 全文立即重算，不需要再点「生成」；正文可直接编辑
   - 预览区顶部有三个**段落开关**：任务 / 碎片 / 笔记，取消勾选后报告里
     不再包含对应段落（勾选即时重生成，所见即所得）；专注统计始终保留
4. **（可选）「AI 润色」**：把当前草稿交给 AI 整理成正式周报，结果回填预览区
   - 需要在 设置 → AI 总配置 配好后端，并在「接入插件」勾选本插件
   - **手动编辑过的草稿会先弹确认再覆盖**（润色是整段替换）；原文随时可改时间范围重新生成找回
5. 导出三选一：复制到剪贴板 / 另存为 .md 文件 / 写入 Obsidian vault（需在设置页配置 vault 路径）
6. **「最近导出」**：另存为 / 写入 vault 的最近 10 条记录（存在插件私有
   目录、重启不丢）；点菜单项直接**打开文件所在文件夹**，也可一键清空记录

## v1.1.0 权限说明

AI 润色需要联网调模型，本插件的声明能力从**只读**变为 `network + ai`：
只在点「AI 润色」那一刻发请求，发送内容 = 当前预览区草稿，绝不后台
静默上传、不附带其他应用数据（审计行见 `app.log` 的 `[插件网络]`）。
不接 AI 总配置时插件行为与旧版完全一致（草稿 / 复制 / 另存 / vault）。

## 数据来源（只读，不改动你的数据）

| 内容    | 来源                                         |
| ----- | ------------------------------------------ |
| 已完成任务 | 按完成时间归入所选周期                                |
| 碎片    | 按内容类别分组展示                                  |
| 番茄计数  | 任务的累计 focus_sessions（按任务统计，非时间区间，报告内会如实标注） |

## 注意

- 草稿只是初稿，语气和取舍请自己把关后再交
- 「写入 Obsidian」需要先在设置页配置 vault 路径，否则该按钮不可用
- 插件只读宿主数据，不会修改/删除任务、碎片、笔记
- 想临时停用：主窗口左栏「插件中心」→ 本插件卡片上点「停用」
  （停用后不挂右键菜单、不绑热键，随时可「启用」恢复）
