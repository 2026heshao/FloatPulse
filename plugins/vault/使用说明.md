# 密码保险箱（vault）

一个**只活在你这台电脑里**的密码保险箱：自定义字段收纳账号密码、API Key、服务器信息等任意机密，**Ctrl+Alt+B 一秒取用**，复制后 30 秒自动清剪贴板。不联网、不云同步、不做自动捕捉——它是离线的，所以它不欠任何人的账。

加密是双因子：Windows 系统账户（DPAPI）+ 你的主密码（PBKDF2 二十万次迭代派生）。两把钥匙**缺一把都解不开**——文件被拷到别的电脑是乱码，忘了主密码同样解不开（**真的无法找回**，首次创建时会让你二次确认）。

## 怎么用

1. **创建**：主窗口左栏「🔒 密码保险箱」→ 首次进入是创建向导 → 设主密码、再输一遍 → 看清「无法找回」警告 → 确认创建
2. **日常取用**：**Ctrl+Alt+B**（快速取用）→ 打关键词 → 回车 → 首个「机密」字段进剪贴板，30 秒后自动清空
3. **管理**：**Ctrl+Alt+V** 或侧栏进页面 → 左列条目、右侧详情 → 新增 / 编辑 / 删除，字段名完全自定义（账号、密码、API Key、门牌号都行）
4. **机密字段**：勾了「机密」的值默认显示 `••••••••`，点「显示」才显形；复制它走 30 秒倒计时清剪贴板；**搜索永远不会命中机密值**（防肩窥）
5. **自动锁定**：解锁后 5 分钟没操作自动锁回（可改 1 / 5 / 15 分钟或永不），锁定即丢弃内存明文；也可随时点「立即锁定」

## 改主密码 / 换机迁移

- **改主密码**：页面底部「修改主密码」→ 旧密码 + 新密码两遍 → 整库重加密，原有条目不动
- **换机 / 重装系统**：底部「导出明文 JSON」（二次确认）→ 新机器装好插件后用文本编辑器对照录入。**导出的文件是明文，用完立即删除**——DPAPI 绑定本机账户，直接拷 `vault.bin` 过去是解不开的，这是设计如此

## 权限与边界

- **零能力插件**：`capabilities` 是空数组——不联网、不读宿主数据、不写宿主数据，AI 助手等其它插件永远接触不到条目
- 数据存在 `float_data/plugins/vault/`：`meta.json`（派生参数）+ `vault.bin`（整库密文）——条目数、更新时间也一并加密，看文件猜不出你存了几条
- **不防**内存 dump / 调试器（桌面应用的物理边界，不夸大）；**不做**自动捕捉、云同步、密码生成器、浏览器扩展（有意砍掉，见设计文档）
- 卸载插件不会删私有数据目录；「重建保险箱」会把旧文件留档为 `*.corrupt-时间戳`，绝不静默抹掉
