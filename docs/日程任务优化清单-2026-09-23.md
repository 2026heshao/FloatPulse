# 日程任务模块 · 体感与功能优化清单

> 产出：产品经理 许清楚 ｜ 复核与分批建议：交付总监 齐活林
> 日期：2026-09-23
> 依据：v3 代码现状核查（`src/task_manager.py` / `src/tasks_panel.py` / `src/card_window.py`）

## 一句话结论

完成态**既看不到也点不到**（列表无勾选框、标记完成要绕右键、无动效无撤销），截止时间**既不好填也读不出轻重**（主窗口手输日期串、只显示绝对日期、列表按创建顺序排、大小两端还不一致）——这是本模块最大的体感短板。

> 数据层影响提示：B5、A3 涉及字段/逻辑新增（可选 `deadline_time`、`completed_at`、公共状态函数），其余为 UI/交互层改动，不动 `schedule.json` 结构。

## 需要用户拍板的问题

1. **是否引入时分精度**：`deadline` 目前只有日期。加时分会影响输入控件、角标/提醒判定、排序与相对时间文案。建议**本轮不做**，仅预留可选字段位。
2. **已完成任务默认折叠还是默认显示**：折叠更清爽，但「刚勾完想确认一下」会觉得东西消失了。
3. **是否记录完成时间 `completed_at`**：需写新字段（存量自动补空）。它是撤销、按完成时间排序、完成统计的前提。建议**做**。
4. **列表默认排序**：改为按截止时间分组更符合效率工具直觉，但会打破当前「按录入顺序」习惯。建议**直接替换默认**，无日期任务置于末尾。
5. **无截止日期任务如何呈现**：当前允许留空，且角标/托盘提醒都不统计。建议**单列「无日期」分组并明确不参与提醒**。
