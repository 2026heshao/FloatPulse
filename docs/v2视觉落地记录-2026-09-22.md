## 四、踩坑记录（重要）

**重写 QSS 时删掉滚动区透明规则 → 卡片内容区整块变黑。**

`QScrollArea` 的 viewport 在样式表环境里使用系统 `QPalette::Base`；本机系统是深色主题，Base ≈ `#1e1e1e`，于是卡片内容区被画成近黑色。旧 QSS 里的 `QScrollArea#fragScrollArea { background: transparent }` 恰好挡住了这个问题，重写时被删掉就暴露了。

已在 `theme.py` 的两套 QSS 中补回并加注释：
```css
QScrollArea, QScrollArea > QWidget { background-color: transparent; border: none; }
QScrollArea > QWidget > QWidget { background-color: transparent; }
```
**维护提示**：任何"重写 QSS"的改动，都必须保留这几条透明规则。

## 六、待办（未落地）

1. **真·背景模糊**：Qt 自绘只能做到半透明，做不到 HTML `backdrop-filter` 那种模糊桌面。若要对齐，需要走 Windows DWM 云母/亚克力（与 `WA_TranslucentBackground` 互斥，需先做可行性 demo）。
2. **列表行内按钮淡入**：设计稿里行内"复制/删除"是 hover 才从透明淡入；QSS 无法表达"父项 hover 影响子项"，需要自定义行 widget 的 `enterEvent` 实现。
3. **页标题右侧的计数 chip**：需要各面板上报条目数，属跨模块小改。
4. **卡片收起动画**：目前 `hide()` 仍是硬切，可加 140ms 淡出。
5. 窗口主题切换的透明度过渡、Toast 淡出、帮助文档过时文案（B11）。

## 七、卡片 Tab 转场叠影：三轮排查与最终修法（2026-09-22 下午）

**现象**（用户两次反馈）：切换 Tab 时新旧两页会重叠一小段时间；第一轮修完仍"不彻底"。

### 第 1 轮（失败）
旧实现只叠一层「新页快照」并让它从 **opacity 0 淡入** —— 淡入过程中快照半透明，
底下旧页直接透上来。改成「旧页快照滑出 + 新页快照不透明滑入」的双层推挤，
并补 `sendPostedEvents(None, DeferredDelete)` 清掉待删的旧行。

结果：仍有叠影（位移只有 52px 而页宽 360px，两层大面积重叠）。

### 第 2 轮（仍然不彻底）
位移改成整页宽（`slide = w + 8`），几何上"边界相接"。实测几何确实不重叠了：

```
stack = 360x312
旧页快照 geometry=(-180, 0, 360, 312) → 右边界 180
新页快照 geometry=( 180, 0, 360, 312) → 左边界 180
间隙 = 0
```

但**肉眼仍能看到重影**。实测量化后找到了真正的机制：

| # | 实测发现 | 说明 |
|---|---|---|
| 1 | `page.grab()` 里 **88% 的像素 alpha=0** | 页面是透明的（背景归 GlassPanel 管），快照因此是大面积"空洞" |
| 2 | 空洞下方露出的是**真实旧页** | stack 全程停在 `old_idx`，直到动画结束才 `setCurrentIndex` |
| 3 | 两层快照恒有 **8px 缝隙** | 缝隙里露出的同样是真实旧页 |

结论：重影不是位移问题，而是"**遮罩不封闭 + 底层一直摆着旧页**"。
新页的每一处空白都变成了旧页的显示窗口。

### 第 3 轮（最终方案）
给快照垫一层玻璃底能堵住透明，但遮罩下方**已经有**一层真实玻璃，两层叠加会把
内容区刷成纯白（实测：静止 `#F2F2F2` vs 末帧 `#FFFFFF`，逐像素差异 15 万+）。

最终做法 —— **转场期间隐藏真实页面，让遮罩坐在真实玻璃之上**：

1. 抓旧页 / 新页的**内容快照**（透明底，只含文字与控件）；
2. 隐藏整个 `QStackedWidget`（`_finalize_page_transition` 里恢复）；
3. 每帧在一张画布上 `清空 → 贴旧页 → 贴新页`，位移互补
   （`old_off + new_off ≡ slide = w`）→ 严丝合缝、玻璃只画一次；
4. 画布由 `_TransitionCanvas` **按 1:1 绘制**（不用 QLabel —— 它的
   `setScaledContents` 会按逻辑尺寸重采样）；
5. 把卡片内容区上下边距由 14 调到 16，使内容区落在**物理像素网格**上
   （设备偏移 37.5px → 40px），这一条是像素级精确的关键。

数学上遮罩呈现 = 页面内容 over 真实玻璃，与静止态逐像素等价。

### 验证（`v2/check_transition.py`，三条判据全自动）

```
[判据1] 转场期间真实页面已隐藏 = True（下方只有真实玻璃）        → 通过
        遮罩半透明占比 = 83.2% —— 空白处露出的是玻璃而非旧页
[判据2] t=0.5 旧页起点=-180 新页起点=180 → 间隙=0               → 通过
[判据3] 末帧 vs 静止态：超差像素 0 / 173250，最大通道差 2        → 通过
```

出图：`设计稿/验证-转场-中途.png`、`设计稿/验证-转场-帧序列.png`（20/40/60/80% 四帧）。

## 八、设置页 UI 升级（2026-09-22 下午）

**改动点**

| 项 | 改前 | 改后 |
|---|---|---|
| 数字项的加减按钮 | `QSpinBox` 原生上下箭头（约 14×8px，难点击，且与圆角玻璃风格不搭） | 新增 `v2/src/controls.py` 的 `Stepper`：30×30 圆角按钮，悬浮高亮 / 按下回弹 / 到边界自动置灰 / 长按连续调整（400ms 起跳、80ms→45ms 加速）/ 数值可直接键入（回车截断） |
| 加减号字形 | 原生箭头 | `−`(U+2212) + ASCII `+`，17px/700 —— 实测全角「－」在雅黑下会掉成又短又淡的横线，不匹配 |
| 滑杆 | 完全没写 QSS，走原生样式 | 细槽(6px) + 已选段主色 + 14px 圆形手柄（悬浮描边、按下填充主色） |
| 滑杆数值 | `hintLabel` 纯文字 | `valueChip` 胶囊（主色 + 圆角边框） |
| 设置分组 | `settingsGroup` 没有任何 QSS，是透明区 | 半透明内嵌面板（`panel_fill` + `panel_edge` + 12px 圆角），与玻璃壳形成两层质感 |
| 表单字段名 | 普通正文色 | `fieldLabel` 次级文字色，层级更清楚 |
| 主题按钮 / 保存按钮 | 28px 高、无手型光标 | 30/32px、加 `PointingHandCursor` |

**顺带修掉的**：`SettingsPanel.refresh()` 漏刷"临时素材上限/保留天数"两项（切换主题或从别处改配置后，这两个步进器会停在旧值）。

**验证**：`python shot_ui.py light|dark` → `设计稿/v2实机-设置页-light.png`、`-dark.png`；
步进器交互实测：单击 ±（步长按项配置，如剪贴板 +10）、到边界置灰、
键入 8888 → 8888、键入 99999 → 截断为 10000。
