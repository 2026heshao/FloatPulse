## 二、真正站得住的差异点（每条给出对照）

### ✅ ① 碎片 → 管理 → 复习的完整闭环，别人只做一段

| 环节 | FloatPulse | FocusCapture | Floatyball | Flow/Rubick | Snipaste |
|---|---|---|---|---|---|
| 随手收集 | ✅ 快捕条 + 剪贴板 | ✅ 剪贴板 | ⚠️ 拖放 | ❌ | ❌ |
| 内容分类管理 | ✅ 语义分类 + 双轴筛选 | ❌ 仅时间流 | ❌ | ❌ | ❌ |
| 转成任务/笔记 | ✅ | ❌ | ❌ | ❌ | ❌ |
| **复习（知识卡片）** | ✅ docx 数据源随机翻牌 | ❌ | ❌ | ❌ | ❌ |
| 临时素材中转 | ✅ 去重 + 缩略图 + 过期清理 | ❌ | ❌ | ❌ | ❌ |
| 截图钉屏批注 | ✅ 画笔/箭头/马赛克 + 撤销 | ❌ | ❌ | ❌ | ✅（闭源） |

**这是唯一一条别人无法一句话反驳的优势。** 竞品全是「收集工具」或「启动器」，没有把「收集 → 沉淀 → 复习」串起来的。

### ✅ ② 桌面端的间隔重复入口（潜力最大的独占位）

把 Anki 式复习塞进悬浮球+知识卡片，这个组合我在 GitHub 上**没找到第二个开源实现**。

⚠️ 但目前只是「随机翻牌」，**真正的 SM-2 间隔重复算法还在 Roadmap 未实现**。这条现在是潜力，还不是壁垒。

### ✅ ③ 截图钉屏 + 原位批注 + 光标锚定缩放

开源侧几乎空白（PP-screenshot 0 star、已停更；CleanShot X 是 macOS 闭源商业软件）。
闭源侧 Snipaste 是最强对手，但它批注发生在截图阶段而非钉窗上，且不开源。

### ✅ ④ 工程完整度（对作品集有效，对用户不是卖点）

- 232 个 pytest + 离屏 GUI 验证脚本 + 对比度测试护栏
- 9 篇设计/故障文档，含一次多会话并行事故的复盘
- Python 技术栈 = 二次开发门槛远低于 Electron/.NET/WPF

这条**只对招聘方/技术评审有意义**，普通用户不关心测试数。别把它写进「卖点」。

## 三、站不住的点（建议别再这么讲）

| 现有说法 | 为什么不成立 |
|---|---|
| 「轻量、无 Electron」 | 打包后 **71 MB**。对手 Snipaste **18 MB**（第三方下载站数据，【待核实】真实体积）、Flow Launcher 便携版自带 .NET 运行时。Qt 打包不比 Electron 轻，这个叙事一戳就破 |
| 「悬浮球」本身是差异 | Floatyball、FocusCapture、HiJot 都在做，形态不稀缺 |
| 「跨平台」 | 仅 Windows 10/11 |
| 语音 / AI 整理 | **FocusCapture 有**：sherpa-onnx + FireRedASR2 纯离线语音 + AI 整理 + 原文对照预览。这是硬差距 |

## 四、要回答「有没有成熟独立突出点」

**分层答案：**

| 层面 | 结论 |
|---|---|
| 有没有「独特点」 | ✅ **有** —— 闭环完整度 + 桌面复习入口，同赛道无第二家开源实现 |
| 有没有「突出点」 | ⚠️ **半成熟** —— 独占的那张牌（间隔重复）还没做出来，现在靠的是功能组合密度 |
| 有没有「成熟」 | ❌ **没有** —— 0 stars、零外部用户、无 Release 下载数据，未经任何真实用户验证 |

**一句话**：赛道是空的（这是好消息，也是坏消息 —— 可能本身就没人要），你的组合拳在这个空赛道里最接近完整，但最锋利的那招还没出。

## 五、建议：把潜力兑现成壁垒的排序

| 优先级 | 动作 | 为什么排这里 |
|---|---|---|
| P0 | **实现 SM-2 间隔重复算法**，知识卡片按遗忘曲线调度 | 唯一别人没有的东西；做完立刻从「又一个悬浮球」变成「唯一一个会逼你复习的悬浮球」 |
| P0 | **Obsidian Markdown 导出** | 让用户碎片能流进自己已有知识库，解决「数据孤岛」这个最大弃用理由 |
| P1 | README 加一张对比矩阵（就是第二节那张表） | 现在是候选人 3 秒扫一眼就走，得让他第一屏看到「别人做不到的那条」 |
| P1 | 改叙事：「轻量」→「一个球闭环」 | 71 MB 撑不起轻量故事，功能密度才是真的 |
| P2 | 补离线语音 / OCR | 追平 FocusCapture；但这是军备竞赛，不是壁垒 |
